# AlgoVision 🚀

AlgoVision is an interactive web application that helps users understand Data Structures and Algorithms through visual animations and step-by-step execution.

## Features

### Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Searching Algorithms
- Linear Search
- Binary Search

### Data Structures
- Stack Visualization
- Queue Visualization
- Linked List Visualization
- Binary Search Tree (BST) Visualization

### Additional Features
- Custom array input
- Step-by-step algorithm execution
- Speed control for animations
- Algorithm information and complexity analysis
- Responsive UI

## Tech Stack

- React
- TypeScript
- Vite
- TanStack Router
- CSS
