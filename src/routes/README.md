# Explore Algos Now

An interactive Algorithm Visualizer built using React, TypeScript, and Vite.

## Features
- Sorting Visualizations
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort

- Searching Visualizations
  - Linear Search
  - Binary Search

- Data Structures
  - Stack
  - Queue
  - Linked List
  - Binary Search Tree

## Technologies Used
- React
- TypeScript
- Vite
- TanStack Router
- CSS

## Purpose
To help students understand algorithms and data structures through step-by-step visual animations.
